Dashboard Features

Welcome to the Admin Dashboard. Manage the entire Student Management System here.

1. Student Management
  • View All Students: List all students, edit or delete them.
  • Add New Student: Add students with details like roll no, class, parent info.
  • Student Reports: Generate attendance and grade reports.
2. Teacher Management
  • View All Teachers: View details like department, ID, and join date.
  • Assign Subjects: Map subjects to teachers easily.
  • Add New Teacher: Add new teacher records.
3. Assignment Management
  • View All Assignments: Manage assignments, due dates, and teachers.
  • Create Assignment: Add new assignments easily.
  • Assignment Grading: Allow teachers to grade submissions.
4. Attendance Tracking
  • Daily Attendance: Record student attendance every day.
  • Attendance Reports: See detailed attendance analytics.
  • Set Attendance Rules: Define absence handling policies.
5. Student-Teacher Interaction
  • Teacher Assignments: View assignments created by teachers.
  • Feedback Management: Allow two-way feedback.
  • Parent Communication: Engage with parents.
6. Dashboard Analytics
  • Total Students & Teachers: See real-time stats.
  • Performance Metrics: Monitor academic progress.
  • Upcoming Deadlines: View assignment/exam schedules.
7. User Roles & Permissions
  • Role Management: Assign Admin, Teacher, Student roles.
  • Activity Logs: See user action history.
8. Settings
  • School Year Management: Set academic years easily.
  • Email & Notification Settings: Customize alerts.
  • Security Settings: Configure password and login rules.
